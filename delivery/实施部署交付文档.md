## 二、GaussDB 前置条件

部署前确认 GaussDB 满足：

```sql
SELECT version();                                                       -- Kernel 507+
SELECT datcompatibility FROM pg_database WHERE datname=current_database(); -- A（O模式）
SHOW enable_vectordb;                                                   -- on
SHOW maintenance_work_mem;                                              -- 节点会话级 SET 512MB
```

**enable_vectordb 开启**（若 off，POSTMASTER 级需重启）：
```bash
gs_guc reload -D <datadir> -c "enable_vectordb=on"
gs_om -t restart   # 若 reload 无效
```

**建测试库**（可选）：
```sql
CREATE DATABASE n8n_test WITH DBCOMPATIBILITY='A';
```

## 三、部署方式

### 方式 A：Docker 镜像部署（推荐生产）

#### A1. 克隆仓库
```bash
git clone -b dev https://github.com/huaweicloud-samples/database-n8n-gaussdb.git
cd database-n8n-gaussdb
```

#### A2. 构建镜像（需满足环境要求，见"环境要求"节）
```bash
pnpm install
pnpm build            # 全量构建（约 10-20 分钟）
pnpm build:docker     # 产出本地镜像 n8nio/n8n:local
docker tag n8nio/n8n:local n8nio/n8n:gaussdb
```
> 构建一次后镜像可在同环境重复使用；升级适配版本时重新构建。

#### A3. 配置 .env
```bash
cp delivery/.env.example .env
vi .env
# 必填：N8N_ENCRYPTION_KEY=<随机字符串>
# GaussDB 连接在 UI 配（见配置文档.md），不在 .env
```

#### A4. 启动容器
```bash
docker run -d --name n8n-gaussdb \
  -p 5678:5678 \
  --env-file .env \
  -v n8n_data:/home/node/.n8n \
  n8nio/n8n:gaussdb
```

#### A5. 访问 + 配置
1. 浏览器访问 `http://localhost:5678`
2. 创建 owner 账号（首次）
3. Credentials → Add → "GaussDB" → 填 GaussDB 连接（见配置文档）
4. 节点面板搜 "GaussDB" → 见 GaussDB + GaussDB Vector Store

> GaussDB 在另一主机时，确保容器网络可达 GaussDB 端口。

---

### 方式 B：源码部署（开发/测试）

#### B1. 克隆仓库 + 检查环境
```bash
git clone -b dev https://github.com/huaweicloud-samples/database-n8n-gaussdb.git
cd database-n8n-gaussdb
node -v    # 需 ≥ 22.22（见"环境要求"节）
pnpm -v    # 需 ≥ 10.22
```
> 本仓库是完整 n8n 源码 + GaussDB 适配，克隆即可用，无需额外集成。

#### B2. 安装 + build
```bash
pnpm install
pnpm build
```
确认 exit 0，验证节点定义：
```bash
grep -o "gaussDbApi" packages/nodes-base/dist/types/nodes.json | head -1
grep -o "vectorStoreGaussDB" packages/@n8n/nodes-langchain/dist/types/nodes.json | head -1
```

#### B3. 启动
```bash
export N8N_ENCRYPTION_KEY=<随机字符串>
pnpm start
```
访问 `http://localhost:5678`，配置同 A5。

## 五、部署验证

部署后按以下验证（详见测试指南.md）：

1. **健康检查**：`curl http://localhost:5678/healthz` → `{"status":"ok"}`
2. **节点加载**：UI 搜 "GaussDB" → 见 GaussDB + GaussDB Vector Store
3. **凭据配置**：Credentials → GaussDB → 填连接 → Test → 成功
4. **workflow 执行**：GaussDB 节点 → executeQuery → `SELECT version()` → 返回 `GaussDB Kernel 507.0.0`
5. **向量节点**：VectorStoreGaussDB + Embeddings → insert/load

## 六、已知限制

| 限制 | 说明 |
|---|---|
| upsert 不返回行 | O模式 MERGE 无 RETURNING，如需返回 MERGE 后单独 SELECT |
| 自身元数据库未适配 | n8n 自身元数据跑 GaussDB 未实现，自身库用 SQLite/PostgreSQL |
| enable_vectordb 需实例级 | POSTMASTER 级，需 GaussDB 实例配置+重启 |
| 分布式维度上限 1024 | 分布式 >1024 维不支持，节点自动探测 + 友好提示 |
| @n8n/errors ErrorOptions 修复必含 | 不含则 build 失败 |

## 七、交付后运维

- **n8n 升级**：升级时重新集成 GaussDB 适配代码（新增文件不冲突，package.json 注册行需重加）
