# n8n + GaussDB 数据库连接配置文档

> 本文档说明 n8n 连接 GaussDB 的两种配置方式。

## 配置一：n8n 自身元数据库（环境变量）

n8n 自身的 workflow/credentials/execution 等元数据存哪个库，通过环境变量配置：

### 默认（SQLite，无需配置）
n8n 默认用 SQLite，开箱即用，无需任何 DB 环境变量。**推荐首次部署用 SQLite**。

### 切换到 PostgreSQL（n8n 自身库）
```bash
DB_TYPE=postgresdb
DB_POSTGRESDB_HOST=<postgres-host>
DB_POSTGRESDB_PORT=5432
DB_POSTGRESDB_DATABASE=<n8n-db>
DB_POSTGRESDB_USER=<user>
DB_POSTGRESDB_PASSWORD=<password>
DB_POSTGRESDB_SCHEMA=public
```

> **注意**：本次 GaussDB 适配**未实现 n8n 自身元数据跑 GaussDB**（A 维度，P2 未做）。n8n 自身库用 SQLite 或 PostgreSQL，GaussDB 作为**客户在 workflow 里连的存储**（见配置二）。

---

## 配置二：workflow 里连 GaussDB（UI 凭据，核心场景）

客户在 n8n workflow 里用 GaussDB 做智数查询（C 维度）和向量 RAG（B 维度），通过 **n8n UI 的 Credentials 配置**（非环境变量）。

### GaussDb 数据库节点凭据（C 维度，智数查询）

n8n UI → Credentials → Add Credential → 搜 "GaussDB" → 填写：

| 字段 | 说明 | 示例 |
|---|---|---|
| Host | GaussDB 主机 | localhost 或 GaussDB IP |
| Port | GaussDB 端口 | 5432（GaussDB 默认 8000，按实际填） |
| Database | 数据库名 | n8n_test |
| User | 用户名 | appuser |
| Password | 密码 | ****** |
| SSL | SSL 模式 | disable / allow / require |

> 凭据类型名：`gaussDbApi`（n8n 内部标识，UI 显示 "GaussDB"）。

### GaussDB 向量节点凭据（B 维度，RAG 向量）

向量节点（VectorStoreGaussDB / ChatHubVectorStoreGaussDB）**复用 Postgres 凭据**（GaussDB PG 协议兼容）：

n8n UI → Credentials → Add Credential → 搜 "Postgres" → 填写（指向 GaussDB）：

| 字段 | 说明 | 示例 |
|---|---|---|
| Host | GaussDB 主机 | localhost |
| Port | 端口 | 5432 |
| Database | 库名 | n8n_test |
| User / Password | GaussDB 账号 | appuser / ****** |
| SSL | | disable |
| Allow Unauthorized Certs | 自签证书时勾选 | 否 |

> ChatHub 向量节点用专用凭据 "ChatHub GaussDB Store API"（extends postgres + tableNamePrefix）。

## 配置三：GaussDB 实例前置条件

GaussDB 实例本身需满足：

```sql
-- 1. 版本（Kernel 507+）
SELECT version();

-- 2. 兼容模式（O模式 = A）
SELECT datcompatibility FROM pg_database WHERE datname = current_database();
-- 预期：A

-- 3. 向量开关（必须 on，B 维度需要）
SHOW enable_vectordb;
-- 预期：on

-- 4. maintenance_work_mem（建向量索引需 ≥512MB，节点会话级 SET，无需改实例）
SHOW maintenance_work_mem;
```

### enable_vectordb 开启（若为 off）

enable_vectordb 是 POSTMASTER 级参数，**不能会话级 SET**，需改实例配置 + 重启：

```bash
# 方式1：gs_guc（GaussDB 集群）
gs_guc reload -D <datadir> -c "enable_vectordb=on"
# 若 reload 无效（POSTMASTER 级需 restart）：
gs_om -t restart

# 方式2：单机改配置文件
# 找到 gs_inst.cfg 或 postgresql.conf，设 enable_vectordb=on，重启服务
```

开启后 `SHOW enable_vectordb` 返回 `on`。

### 建测试库（可选）
```sql
CREATE DATABASE n8n_test WITH DBCOMPATIBILITY='A';
```

## n8n 启动环境变量（.env）

```bash
# n8n 加密密钥（首次必须设置，否则每次重启 credentials 失效）
N8N_ENCRYPTION_KEY=<随机字符串>

# n8n 监听
N8N_HOST=0.0.0.0
N8N_PORT=5678

# n8n 自身元数据库（默认 sqlite，无需配；若用 postgres 见配置一）
# DB_TYPE=postgresdb
# DB_POSTGRESDB_HOST=...
```

> GaussDB 连接信息**不在此配置**——在 n8n UI 的 Credentials 里配（见配置二）。

## 配置验证

配置完凭据后，在 n8n UI 测试：
1. Credentials → GaussDB → Test → 应显示连接成功
2. 建 workflow → GaussDB 节点 → executeQuery → `SELECT version()` → 执行 → 返回 `GaussDB Kernel 507.0.0`
